# Company Sales Dashboard

## Project Overview

The Company Sales Dashboard is an interactive Power BI project designed to analyze company-wide sales and business performance.

The dashboard provides insights into sales, profit, costs, orders, products, brands, categories, regional performance, and supervisor-level performance.

## Tools & Technologies

- Power BI
- DAX
- Data Modeling
- Data Visualization
